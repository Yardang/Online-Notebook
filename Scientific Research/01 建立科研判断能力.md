
## 1. 怎么判断一篇研究好不好

抓住5个问题：
1. 研究问题：是否重要、清楚，值得回答？
2. 理论依据：为什么作者认为这个问题值得研究？
3. 研究设计：这种方法真的能够回答这个问题吗？
4. 证据质量：数据、测量、统计和分析是否可靠？
5. 结论：坐着的结论有没有超出证据支持的范围？

其中最关键的是第三个问题：好的研究不是使用最复杂的方法，而是使用能够可靠回答研究问题的方法。

## 2. 发展独立研究能力的三个层次

| 能力层次    | 主要表现                   |
| ------- | ---------------------- |
| 研究兴趣与潜力 | 有好奇心，能提出问题，愿意质疑        |
| 初步研究能力  | 能读懂论文、理解方法、参与数据分析、解释结果 |
| 独立研究能力  | 能设计、实施、修正并完成有学术价值的研究   |
当前最需要补强的是：能否清楚地解释一个研究问题如何产生、为何采用某种设计、如何分析证据，以及从结果中能得出什么结论。
而非急着证明自己能提出一套颠覆性的理论体系。

## 3. 科学写作训练：Science Research Writing

核心：教你怎样把研究组织成一篇符合学术规范的英文论文。
- introduction：为什么要从已有知识逐步引出研究空白
- methods：怎样清楚地交代研究设计
- results：怎样客观地报告发现
- discussion：怎样解释结果、连接已有研究并说明局限

主要教授科学写作，不是系统教研究设计、统计方法或科研思维。
使用方法：现在写NSSI论文的哪个部分，就读对应的章节，再实际写出来。

## 4. 如何与导师沟通、请教

### 4.1 请教的内容

可以把向导师请教的问题拆成两个不同的层面
#### 层面1: 研究问题

e.g., 基于我们已有的数据，您认为目前最值得回答的科学问题是什么？我们是理论贡献不足，还是研究设计本身无法支持有意义的结论？

#### 层面2: 研究方法

e.g., 对于这个研究问题，我考虑了A和B两种分析方法，他们分别有这些假设和局限，您认为哪一种更合适？
（如果导师不熟悉相关方法，不一定能够给出具体的统计指导，这时就需要找统计方法老师、有相似研究经验的博士生，或者其他熟悉该方法的研究者）

注意：科研首先是获得可信的答案，而非制造漂亮的结果。
不要为了让数据显得有卖点，就不断尝试分析方法直到找到显著结果。
探索性分析可以做，但要如实记录哪些是事先计划的分析，哪些是看到数据后提出的新假设，并控制多重检验等风险。

### 4.2 请教的时机

可以用一个很简单的原则：**只要反馈可能影响下一步的研究方向，而且错误方向会造成明显的时间或质量损失，就应该尽早请教。**

不需要等到事情做砸，也不需要证明自己已经付出了最大努力。

以NSSI论文为例，三个反馈节点：
1. 研究问题确定前
	1. 找课题导师：这个问题重要吗？与已有研究相比有什么贡献？
2. 正式分析数据前
	1. 找方法学导师或统计研究者：这个分析计划合理吗？数据支持什么结论？
3. 获得初步结果后
	1. 找课题导师讨论：结果是否可信？是否回答了原始问题？哪些地方需要修正？

（中间遇到重要障碍也可以随时请教，不需要机械地等到某个节点）

### 4.3 合适的汇报结构

核心问题 -> 已做尝试 -> 我自己的初步判断-> 当前局限 -> 需要什么指导

e.g., 不是问“应该用什么方法”，而是说“我倾向于A，因为它能够回答X，但不确定Y假设是否成立”。
这样能够让导师更容易给予有针对性的反馈，也能训练我的判断能力。

### 4.4 如果导师给不了指导怎么办

的确存在这个风险，但是这是一个正常的项目风险，而非我不应该提问的理由。

可以判断：
- 是导师缺乏对应方法知识、没有足够时间？-> 寻找其他指导资源
- 还是我提出的问题不够具体？-> 重新组织问题

一个导师不必掌握所有方法，但一个研究者需要逐渐学会组织自己的支持网络。

未来选择PhD导师时应该重点考察的事情：不仅看对方的研究方向，还要看ta如何训练学生、提供反馈，以及是否愿意帮助学生获得自己无法直接提供的方法支持。

### 4.5 如何在自身判断能力不够时处理不同来源的专业判断

当我还没有足够的专业能力判断一个建议是否正确时，我应该如何利用不同专家的意见，而不只是选择相信其中一个人？
##### - 如果两个导师给出不同意见，怎么办？
##### - 首先建立一个原则：先弄清楚他们为什么得出不同结论，不要急着判断谁更权威。

❌我应该相信哪位老师
✅哪一种方法的理由更充分

譬如临床心理学导师建议使用回归分析，另一位方法学研究者建议采用多层模型。
不需要立即判断谁的统计水平更高，可以先问：
1. 两种方法分别想回答什么问题？
2. 它们各自需要满足什么条件？
3. 哪一种更符合我们的研究问题和数据结构？

e.g., 我的数据来自多所寄宿学校，同校学生可能具有共同的环境特征。
- 多层模型：可能更合理地处理这种群集结构，而不只是因为更高级。
- 使用群集稳健标准误等方法也可能是可行的选择。

可以把不同意见简单记录在同一张表里：

|     | 导师A      | 导师B      |
| --- | -------- | -------- |
| 建议  | 方法A      | 方法B      |
| 理由  | 为什么适合    | 为什么适合    |
| 前提  | 需要满足什么条件 | 需要满足什么条件 |
| 风险  | 可能有什么偏差  | 可能有什么偏差  |
##### 不同专家的意见并不一定具有同等分量，需要根据具体问题判断谁拥有相关经验

- 临床心理学导师啃根更擅长判断研究问题的临床意义
- 统计研究者可能更擅长判断模型是否合理
- 熟悉农村儿童研究的学者可能更清楚亲子分离指标的测量和解释问题

## 5. AI可以提供的帮助

以NSSI研究为起点
可以先只完成一个小目标：**把目前的NSSI数据、研究问题和已有分析整理清楚，然后一起判断下一步应该怎样推进**

在这个过程中，AI可以带着练习（BTW这是一个很好的AI native教学工作流，有domain knowledge的人先规定好一个合适的教学计划和大纲，然后AI带着逐步训练与习得过程中的能力）：
1. 怎样筛选论文
2. 评估研究设计
3. 选择分析方法
4. 理解统计结果
5. 怎样向导师提出有价值的问题

## 6. 心法

1. 我的目标应该是把事情做成，而不是证明我尽到了自己最大的努力。
	1. 真正值得培养的科研独立性，不是一个人能扛住多少困难，而是能否有效地识别问题、调动资源、接受反馈，并持续改进自己的判断。
2. 对于人际交往的麻烦与压力
	1. 划定受困扰（揣度心理）的最小范围，而非一直卷入其中。追求成熟的工作态度，相信大家都是有一定自主判断能力和情绪处理能力的成年人，而非来访或小孩。
		1. 我需要确保和追求自己工作态度成熟。在工作表现中不成熟的人，他们的情绪不是我的责任。
	2. 优先做有意义的、有价值的事情，而非麻烦、棘手的事情，把时间、精力实质上投入到哪里，就会在哪里取得进步。
